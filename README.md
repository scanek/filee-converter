# Filee Converter Web Service

Автономный веб-сервер и REST API для конвертации файлов в Docker на базе движка Filee.

## Основные возможности

- **Более 270 поддерживаемых форматов**: офисные документы, изображения, аудио, видео, архивы, электронные книги, 3D-модели и векторная графика.
- **Полная приватность**: все операции выполняются локально на вашем сервере, файлы не отправляются на сторонние сервисы.
- **Поддержка кириллицы**: корректная обработка русских названий файлов и документов со сложной версткой.
- **Встроенные движки**: LibreOffice (Writer/Calc), FFmpeg, Pandoc, Ghostscript и Tesseract OCR (русский и английский языки).
- **Современный веб-интерфейс**: удобная область drag-and-drop, быстрый выбор популярных форматов, индикация статуса и автоскачивание.
- **REST API**: эндпоинты для программной интеграции и автоматизации.

## Быстрый старт с Docker Compose

1. Клонируйте репозиторий:
```bash
git clone https://github.com/scanek/filee-converter.git
cd filee-converter
```

2. Запустите контейнер:
```bash
docker compose up -d
```

3. Откройте в браузере:
```
http://localhost:8089
```

## Конфигурация

Порт сервиса можно изменить через файл `.env` или переменную окружения:

```env
PORT=8089
```

## Использование через REST API

### Проверка работоспособности
```bash
curl http://localhost:8089/api/health
```

### Конвертация файла
```bash
curl -X POST "http://localhost:8089/api/convert" \
  -F "file=@document.docx" \
  -F "target_format=pdf" \
  -o "document.pdf"
```

## Поддерживаемые категории форматов

- **Документы**: DOCX, DOC, PDF, RTF, ODT, XLSX, XLS, CSV, PPTX, TXT, HTML, MD, EPUB, FB2.
- **Изображения**: WEBP, PNG, JPG, JPEG, TIFF, BMP, SVG, ICO, HEIC, AVIF, PSD.
- **Аудио и видео**: MP4, MKV, AVI, WEBM, MOV, MP3, FLAC, WAV, OGG, AAC, M4A.
- **Архивы**: ZIP, 7Z, TAR, GZ, BZ2, XZ, RAR (распаковка).
- **Распознавание текста (OCR)**: изображения и сканы в текст (TXT, PDF).

## Структура проекта

- `app.py` — серверная часть на FastAPI (обработка запросов, вызов CLI, очистка временных файлов).
- `static/index.html` — адаптивный веб-интерфейс.
- `bin/` — исполняемые файлы ядра Filee.Cli.
- `Dockerfile` — сборка контейнера с необходимыми системными утилитами и шрифтами.
- `docker-compose.yml` — манифест для быстрого запуска сервиса.
