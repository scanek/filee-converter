# Filee Converter Web Service

Автономный веб-сервер и REST API для приватной конвертации и обрезки файлов в Docker на базе движка Filee и FFmpeg.

## Основные возможности

- **Более 270 поддерживаемых форматов**: офисные документы, изображения, аудио, видео, архивы, электронные книги, 3D-модели и векторная графика.
- **✂️ Встроенная обрезка аудио и видео**: нарезка медиафайлов по таймкодам (начало и конец) с предпросмотром во встроенном плеере.
- **Конвертация видео в GIF и извлечение аудио**: обрезка видео с прямой конвертацией в GIF или извлечением нужного фрагмента в MP3/WAV/AAC.
- **Полная приватность**: все операции выполняются локально на вашем сервере, файлы не отправляются на сторонние сервисы.
- **Поддержка кириллицы**: корректная обработка русских названий файлов и документов со сложной версткой.
- **Встроенные движки**: LibreOffice (Writer/Calc), FFmpeg, Pandoc, Ghostscript и Tesseract OCR (русский и английский языки).
- **Современный веб-интерфейс**: адаптивная темная тема, drag-and-drop, кнопки популярных форматов, видео/аудио плеер с кнопками фиксации текущего времени и автоскачивание.
- **REST API**: эндпоинты для программной интеграции и автоматизации.

## Быстрый старт с Docker Compose

1. Клонируйте репозиторий:
```bash
git clone https://github.com/scanek/filee-converter.git
cd filee-converter
```

2. Запустите контейнер:
```bash
docker compose up -d
```

3. Откройте в браузере:
```
http://localhost:8089
```

## Конфигурация

Порт сервиса можно изменить через файл `.env` или переменную окружения:

```env
PORT=8089
```

## Использование через REST API

### Проверка работоспособности
```bash
curl http://localhost:8089/api/health
```

### Стандартная конвертация документа
```bash
curl -X POST "http://localhost:8089/api/convert" \
  -F "file=@document.docx" \
  -F "target_format=pdf" \
  -o "document.pdf"
```

### Обрезка видео / аудио по таймкодам
```bash
# Обрезка видео с 10-й по 45-ю секунду
curl -X POST "http://localhost:8089/api/convert" \
  -F "file=@video.mp4" \
  -F "start_time=00:00:10" \
  -F "end_time=00:00:45" \
  -F "target_format=mp4" \
  -o "trimmed_video.mp4"
```

### Обрезка видео и конвертация фрагмента в GIF
```bash
curl -X POST "http://localhost:8089/api/convert" \
  -F "file=@movie.mp4" \
  -F "start_time=00:01:20" \
  -F "end_time=00:01:25" \
  -F "target_format=gif" \
  -o "highlight.gif"
```

### Извлечение аудиодорожки из фрагмента видео
```bash
curl -X POST "http://localhost:8089/api/convert" \
  -F "file=@concert.mkv" \
  -F "start_time=00:15:30" \
  -F "end_time=00:18:45" \
  -F "target_format=mp3" \
  -o "song.mp3"
```

## Поддерживаемые категории форматов

- **Документы**: DOCX, DOC, PDF, RTF, ODT, XLSX, XLS, CSV, PPTX, TXT, HTML, MD, EPUB, FB2.
- **Изображения**: WEBP, PNG, JPG, JPEG, TIFF, BMP, SVG, ICO, HEIC, AVIF, PSD, GIF.
- **Аудио и видео**: MP4, MKV, AVI, WEBM, MOV, MP3, FLAC, WAV, OGG, AAC, M4A, Opus.
- **Архивы**: ZIP, 7Z, TAR, GZ, BZ2, XZ, RAR (распаковка).
- **Распознавание текста (OCR)**: изображения и сканы в текст (TXT, PDF).

## Структура проекта

- `app.py` — серверная часть на FastAPI (конвертация, обрезка FFmpeg, очистка временных файлов).
- `static/index.html` — адаптивный веб-интерфейс с медиаплеером и панелью обрезки.
- `bin/` — исполняемые файлы ядра Filee.Cli.
- `Dockerfile` — сборка контейнера с необходимыми системными утилитами и шрифтами.
- `docker-compose.yml` — манифест для быстрого запуска сервиса.
